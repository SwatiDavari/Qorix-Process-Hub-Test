# Proposal: Qorix process extensions for Eclipse SCORE

Generated by `qpm export-upstream` from the Qorix overlay. Each change is additive
(superset rule), so existing SCORE content remains valid.

## Changes

- **extend_enum** `safety` - SCORE caps safety at ASIL_B. Qorix products (e.g. CP) are developed to ASIL D; ASIL_A/ASIL_C are needed as decomposition results (ISO 26262-9 clause 5).
- **extend_element_type** `stkh_req` - SCORE lists CAL as TBD; attribute is optional so SCORE content stays valid.
- **extend_element_type** `feat_req` - Optional CAL attribute, as for stkh_req.
- **extend_element_type** `comp_req` - Optional CAL attribute, as for stkh_req.
- **extend_element_type** `aou_req` - Optional CAL attribute, as for stkh_req.
- **extend_element_type** `feat` - Optional CAL attribute, as for stkh_req.
- **extend_element_type** `comp` - Optional CAL attribute, as for stkh_req.
- **extend_element_type** `mod` - Optional CAL attribute, as for stkh_req.
- **add_rule** `qx__arch_asil_d_fulfilment` - Flags lower-integrity elements fulfilling ASIL D requirements unless decomposed.
- **extend_element_type** `workproduct` - Each work product links its concept and its template, making WPs self-describing.
