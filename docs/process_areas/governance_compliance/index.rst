Governance & Compliance
#######################

Own the Qorix process framework: maintain the Qorix overlay on top of Eclipse SCORE, approve project tailoring, run compliance audits, and feed improvements back to SCORE through the Qorix Fork.

* **Tier:** qorix
* **Owner:** :need:`rl__qx_gc_head`
* **Standards:** ISO 26262-2, ISO/SAE 21434 cl. 5-6, ASPICE 4.0 PIM.3 / SUP.1 / MAN.3

.. doc_concept:: Qorix Process Tiering Concept
   :id: doc_concept__qx_gc_process
   :status: valid
   :version: 1
   :tags: governance_compliance

   Three tiers compose every project's process: (1) the Eclipse SCORE baseline,
   imported unchanged; (2) the Qorix overlay, which may only add or widen
   (superset rule); (3) the project tailoring, which may only narrow and must
   justify each narrowing. The resolved model is generated, never hand-edited.
