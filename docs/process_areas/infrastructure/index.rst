Infrastructure
##############

Provide and keep qualified the docs-as-code toolchain (Bazel, Sphinx-needs, qpm), the repository baseline and CI that every Qorix project consumes.

* **Tier:** qorix
* **Owner:** :need:`rl__qx_infra_lead`
* **Standards:** ISO 26262-8 cl. 11, ISO/SAE 21434 cl. 5.4.5, ASPICE 4.0 PIM.3

.. doc_concept:: Infrastructure Concept
   :id: doc_concept__qx_infra
   :status: valid
   :version: 1
   :tags: infrastructure

   One framework module (Bazel `bazel_dep`) per release. Projects never copy process
   content; they reference a framework version and add only their tailoring. Tool
   changes are qualified once, centrally.
