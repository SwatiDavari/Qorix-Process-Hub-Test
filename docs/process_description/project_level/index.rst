Project Level
#############

What belongs at this level, and what does not
=============================================

Processes a project carries out for its own product and that no other project shares. Anything that applies to every project belongs at the :ref:`qx_organisation_level`; project-specific tools and solutions belong in the project's own documentation.

How this level relates to the two above it
==========================================

Eclipse S-CORE is the base, the Qorix organisation level adds to it, and a project level area adds only what neither covers. Tailoring of inherited processes is recorded in the tailoring reports, not here.

How each area is modelled
=========================

The same model as the organisation level: set ``level: project`` in the area's YAML file.
