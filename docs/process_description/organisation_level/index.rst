Organisation Level
##################

Our goal
========

One set of company-wide processes that every Qorix project inherits, so a project only describes what is specific to its product.

What this level covers
======================

Processes that apply to Qorix as a company, independent of any project: governance and compliance, shared infrastructure, training and validation support. Each one is a process area below.

How this section is modelled
============================

Every area uses the same process model - workflows, work products, roles and guidance - authored as YAML in ``process/areas`` and rendered to these pages (see :ref:`qx_process_introduction`).

How this section relates to the project level
=============================================

Projects apply these processes and narrow them in their tailoring; they do not redefine them. See :ref:`qx_project_level`.
