Qorix Process Framework
#######################

One process framework for all Qorix projects: Eclipse S-CORE as the baseline, a Qorix
overlay for ASIL D / CAL 3 and the Qorix process areas, and a per-project tailoring -
composed from a technology-neutral metamodel.
