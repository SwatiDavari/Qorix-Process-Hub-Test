Process standards
#################

The primary standard behind each process area of the hub. The scope is Qorix: they apply at organisation level and every project inherits them. Clause level compliance is on the :ref:`Needs <qx_needs>` page.

.. list-table::
   :header-rows: 1
   :widths: 24 18 44 14

   * - Process area
     - Primary standard
     - Purpose
     - Scope
   * - Organizational Process Definition
     - ISO 9001
     - Defines organization-wide process management and continual improvement
     - Qorix
   * - Process Architecture / Process Framework
     - APQC PCF
     - Standard business process taxonomy and enterprise process structure
     - Qorix
   * - Business Process Modeling
     - BPMN 2.0
     - Standard notation for documenting and visualizing processes
     - Qorix
   * - Software Lifecycle Processes
     - ISO/IEC/IEEE 12207
     - Defines software lifecycle processes, activities, and outcomes independent of tools and methodologies
     - Qorix
   * - System Lifecycle Processes
     - ISO/IEC/IEEE 15288
     - Defines system engineering and lifecycle processes
     - Qorix
   * - Software Testing Processes
     - ISO/IEC/IEEE 29119
     - Defines generic software testing processes applicable to any lifecycle model
     - Qorix
   * - Configuration Management
     - ISO 10007:2017
     - Guidelines for configuration management throughout product/service lifecycle
     - Qorix
   * - Configuration Management Governance
     - SAE EIA-649C
     - Industry-standard CM principles, planning, identification, change control, status accounting, and audits
     - Qorix
   * - Process Assessment
     - ISO/IEC 330xx (SPICE)
     - Process capability measurement and assessment
