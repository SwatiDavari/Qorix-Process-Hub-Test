KPI register
############

A KPI is a measurable statement about an outcome. It has a formula, a unit, a goal, a limit and an owner. The hub defines each KPI once, at organisation level; projects measure it and report the value. A KPI hangs under one outcome (``measures``), so it joins the thread objective, policy, outcome, workflow, work product.
