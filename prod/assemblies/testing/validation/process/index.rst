Validation
##########

Set the organisation-wide test policy, qualify the test systems it relies on, and validate products against stakeholder requirements.

* **Assembly:** Testing / Validation (code ``val``)
* **Status:** :bdg-secondary:`draft`

.. doc_concept:: Validation Concept
   :id: doc_concept_qx_val_validation
   :status: valid
   :version: 1
   :tags: validation

   The test policy defines what "enough testing" means per ASIL/CAL. Test systems
   (HIL, SIL, target rigs) are configuration items with their own qualification.
   Validation closes the loop from stakeholder requirements to the released product.
