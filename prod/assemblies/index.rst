Assemblies
##########

Each assembly is one Qorix process. It answers **A -> B: how, who, when, by what means, what** - with workflows (IN work products -> activities -> OUT work products), the roles that perform them (responsible, approver, expertise) and the work products and templates they use. The process model is described in :ref:`qx_process_model`.

Assemblies are grouped into cluster assemblies. Each is classified by enabler, scope and layer:

.. list-table::
   :header-rows: 1
   :class: qx-reg

   * - Enabler
     - Scope
     - Layer
   * - PRD, TST, BLD, DOC, SAF, SEC
     - GLOB, FEAT, COMP, UNIT
     - INT, REQ, ARC, DES, IMP
