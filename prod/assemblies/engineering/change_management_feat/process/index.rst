Change Management (Feature)
###########################

The change management process applied to one feature. The same shape as the organisation level process, one scope down; a feature change that reaches an organisation level work product is escalated to it.

   This is a pilot of the scope axis. It shows how a process is repeated one scope down.

   The feature level process reuses the outcome and the capabilities of the organisation level process. A feature change package that touches an organisation level work product is passed up as an input to the organisation level change process.
