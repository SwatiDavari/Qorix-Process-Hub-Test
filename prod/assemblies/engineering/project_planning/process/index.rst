Project Planning and Control
############################

Plan a project's scope, schedule, resources and responsibilities, and control progress against that plan.

* **Assembly:** Engineering / Project Planning and Control (code ``plan``)
* **Status:** :bdg-secondary:`draft`
* **Enabler / Scope / Layer:** - / GLOB / -
* **Owner:** :need:`rl_qx_plan_project_manager`
* **Standards:** ISO/IEC/IEEE 15288 6.3.1-6.3.2, ASPICE 4.0 MAN.3

.. doc_getstrt:: Getting started on Project Planning and Control
   :id: doc_getstrt_qx_plan_getting_started
   :status: valid
   :version: 1
   :tags: project_planning

   This describes how to plan and control a project at organisation level: what every Qorix project's plan must contain and how progress is reviewed.

   Use it when a project is commissioned or when a plan is re-baselined. A project's own schedule and task list stay in the project; this process defines the plan content and the review rhythm.

.. outcome:: Each project has an approved plan

   :status: draft

   :tags: project_planning
   :complies: std_req_iso15288_631, std_req_aspice_40_man_3

   Every project has a plan approved before work starts that states scope, schedule, resources, responsibilities and the processes it applies.

.. outcome:: Progress is assessed against the plan and deviations are acted on

   :status: draft
   :version: 1

   :complies: std_req_iso15288_632, std_req_aspice_40_man_3

   Project progress is reviewed at a defined cadence against the plan, and each deviation has an owner and a recorded action.
